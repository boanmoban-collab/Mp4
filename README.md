# استوديو كليب وأغاني طلال جالس تحت الشجرة 🎵
### Talal Under The Tree - Music Video & Audio Studio

تطبيق ويب واستوديو تفاعلي متكامل لإنتاج وتصميم فيديو كليب غنائي شرقي متزامن مع كلمات الأغنية، مع إمكانية التسجيل والتنزيل المباشر بصيغة **MP4 / WebM**، ودعم البناء التلقائي عبر GitHub Actions.

## ✨ المميزات الرئيسية (Key Features)

1. **مسرح العرض الغنائي ثلاثي الأبعاد والحي (1280x720 HD Canvas Visualizer):**
   - حركة فنانة على خشبة المسرح بأزياء سهرة محتشمة وأنيقة مع مايكروفون، تتمايل وتغني بحركات انسيابية متوافقة مع الإيقاع.
   - حركة وتصفيق وتفاعل الجمهور والمستمعين في الصالة على كل ضربة "دوم" و"تاك" وتصفيق الأكف.
   - كشافات مسرحية متحركة، ذرات غبار وشرارات ذهبية، وتأثيرات أضواء ليزرية متغيرة.
   - شريط كاريوكي تفاعلي يبرز كل شطر مع تقدم اللحن.

2. **محرك الموسيقى والنغمات الشرقية الأصيلة (Web Audio API Engine):**
   - ألحان شرقية ثرية بنغمات العود والكمان والقانون مع درجات طربية أصيلة (مقام بياتي/راست/حجاز).
   - إيقاعات طربية متعددة: **مقسوم**، **ملفوف راقص**، **صعيدي طربي**، **بلدي متمايل**، و**بوب راقص**.
   - ضربات دربكة حية (دوم عميق، تاك رنان، صك حاد، ورق، وتصفيق إيقاعي).
   - إمكانية الغناء المباشر عبر المايكروفون مع صدى ومؤثرات صوتية، أو تلاوة لحنية متزامنة.

3. **تسجيل وبناء الفيديو كليب (MP4 / WebM) برابط تحميل مباشر:**
   - بضغطة زر واحدة يبدأ الاستوديو تسجيل المسرح الحي بدقة 720p HD مع الصوت المدمج.
   - فور انتهاء الأغنية يظهر مشغل فيديو للمعاينة مع زر **تحميل مباشر لفيديو MP4** إلى جهازك فوراً.

4. **البناء التلقائي عبر GitHub Actions Workflow (`.github/workflows/main.yml`):**
   - يحتوي المستودع على إعداد جاهز لـ GitHub Actions لبناء التطبيق وأرشفة ملفات الفيديو تلقائياً فور الرفع (Push) إلى GitHub وإتاحة رابط التحميل المباشر كـ Artifact.

## 🚀 التشغيل المحلي والتطوير (Local Development)

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل السيرفر المحلي
npm run dev

# 3. بناء المشروع للإنتاج
npm run build
```

---

## 🎬 تصدير الفيديو المباشر من التطبيق:
1. افتح التطبيق في المتصفح.
2. اضغط على زر **"بدء بناء وتصدير الفيديو"**.
3. انتظر حتى اكتمال الأغنية أو اضغط "إنهاء وحفظ الآن".
4. انقر فوق زر **"تحميل فيديو كليب MP4 مباشرة"**.
